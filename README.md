## Setup

To run this portfolio app locally, follow these steps (Node.js 20.9 or newer):

1. Clone the repository: `git clone https://github.com/L3VU5/portfolio-paweljedrasik`
2. Navigate to the project folder: `cd portfolio-paweljedrasik`
3. Install dependencies: `npm install`
4. Start the dev server: `npm run dev`

## Scripts

- `npm run dev` - development server
- `npm run build` / `npm start` - production build and server
- `npm run lint` - ESLint
- `npm test` - Jest and Testing Library
